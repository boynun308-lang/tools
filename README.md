# AI Story Translator

A fully functional web application to automatically dub and translate video stories.

## Features
- Upload videos (MP4, AVI, MOV, etc.)
- Auto-extract audio & transcribe using OpenAI Whisper.
- Translate scripts seamlessly using OpenAI (Perfect for Khmer context).
- Generate high-quality natural voices via Edge-TTS (No API key needed, includes native Khmer male/female voices).
- Restitch audio and video automatically using FFmpeg.
